Desktop icon installers  |  مثبّتات أيقونة سطح المكتب
=====================================================
1) Edit app-url.txt and put your real GitHub Pages address
   عدّل app-url.txt وضع رابط موقعك على GitHub Pages
   (default: https://danial56hd-wq.github.io/calculator-app/)
2) Windows : double-click install-windows.bat
   Linux   : sh install-linux.sh
   macOS / Android / iPhone: open the site in Chrome/Safari and use "Install app / Add to Home Screen"
