## 🚀 التشغيل السريع

### 1. فتح مباشر
افتح ملف `index.html` في أي متصفح حديث.

### 2. خادم محلي (موصى به للتثبيت)
```bash
# Python
python -m http.server 8000

# أو Node
npx serve .
```
ثم افتح: http://localhost:8000

### 3. نشر مجاني
- [Netlify Drop](https://app.netlify.com/drop) — اسحب المجلد
- GitHub Pages / GitLab Pages / Codeberg Pages

> ⚠️ التثبيت كـ PWA يتطلب **HTTPS** أو `localhost`.

## 📲 التثبيت (Install)

| الجهاز | الطريقة |
|--------|---------|
| **Chrome / Edge (حاسوب)** | أيقونة ⊕ في شريط العنوان أو زر «تثبيت التطبيق» داخل الإعدادات |
| **Android** | ⋮ ← Install app / إضافة إلى الشاشة الرئيسية |
| **iPhone / iPad (Safari)** | زر المشاركة ⬆ ← إضافة إلى الشاشة الرئيسية |

بعد التثبيت يعمل التطبيق كبرنامج مستقل ويدعم وضع عدم الاتصال.

### 🖥 أيقونة على سطح المكتب
المتصفحات لا تسمح لأي صفحة بوضع أيقونة على سطح المكتب تلقائياً؛ لذلك توجد 3 طرق:
1. **التثبيت كـ PWA** (زر «تثبيت التطبيق» أو «اختصار على سطح المكتب» في الإعدادات) — يضيف الأيقونة الذهبية تلقائياً.
2. **مجلد `desktop/`**: عدّل `app-url.txt` بعنوان موقعك ثم شغّل `install-windows.bat` (ويندوز) أو `sh install-linux.sh` (لينكس) لإنشاء اختصار بالأيقونة على سطح المكتب.
3. تنزيل ملف اختصار (`.url` / `.webloc` / `.desktop`) من زر «اختصار على سطح المكتب» في الإعدادات.

## 🚢 الرفع على GitHub عبر Actions

1. ارفع محتويات المجلد (بما فيها `.github/`) إلى فرع `main`.
2. من **Settings ← Pages** اجعل **Source = GitHub Actions**.
3. عند كل `push` يعمل الـ workflow: يفحص الملفات (`scripts/validate.mjs`) ثم ينشر الموقع على GitHub Pages.

## الجديد في هذا الإصدار / What's new

- **آلة حاسبة علمية**: زر «🔬 علمي» أعلى لوحة المفاتيح — sin/cos/tan وعكسها وhyperbolic، ln/log/log₂، eˣ، 10ˣ، x²/x³/xʸ، 1/x، |x|، ∛، ℯ، floor/ceil، مع تبديل DEG/RAD.
- **الرموز العلمية** (العلوم والرياضيات): الجبر، المجموعات والمنطق، التفاضل والتكامل، اليونانية، الأسس والأدلة والكسور، الفيزياء، وحدات SI، ثوابت فيزيائية، رموز الكيمياء، والعناصر الـ118 — اضغط لإضافة الرمز ثم انسخ.
- **أدوات القياس**: أشكال إضافية (قطاع، حلقة، نصف دائرة، مثلث قائم) بالمساحة والمحيط، حجم الخزان ووزن السائل، محوّل السوائل، ووحدات وزن إضافية.
- **صندوق أدوات المطوّر**: JSON، Base64، URL، Unix Timestamp، ألوان HEX، Regex، إحصائيات النص، UUID.
- **إصلاحات**: إزالة صيغتي `??=` و`??` التي كانت تعطّل التطبيق بالكامل على المتصفحات القديمة، وإصلاح الأصفار الزائدة (`005`). أضاف `scripts/validate.mjs` فحصاً يمنع رجوعهما.
